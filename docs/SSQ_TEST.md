# 멀미 저감 효과 평가 — SSQ 사용자 테스트 (#46)

멀미 편의 옵션(#6: 유리 틴트 + 수평 유지)이 실제로 멀미를 줄이는지, 같은 사람이 **옵션 끔(A)** 과 **옵션 켬(B)** 으로 한 번씩 달리고 **SSQ(Simulator Sickness Questionnaire)** 점수를 비교합니다.

> ⚠️ **진행 전 확인(팀)**: 사람 대상 설문이라 수업에서 따로 필요한 절차(동의서 양식 등)가 있는지 교수님/조교께 먼저 확인합니다. 아래 안내문은 기본안입니다.

## 1. 설계

| 항목 | 내용 |
| --- | --- |
| 조건 | **A = 편의 옵션 끔**, **B = 편의 옵션 켬** (#6 프리셋 — 왼손 **X 1.5초**로 전환, `COMFORT ON/OFF` 표시) |
| 순서 | 참가자 번호 **홀수 A → B, 짝수 B → A** (순서 효과를 상쇄) |
| 주행 | `Track_Main`(서킷) **타임어택 3랩**(약 3분) — AI·아이템이 없어 조건마다 똑같음. **설정에서 고스트 표시 끔**(둘째 판에 고스트가 생기면 조건이 달라짐) |
| 측정 | ① SSQ 16문항: 시작 전 1번 + 조건마다 주행 직후 ② 완주 시간 ③ 중도 포기 여부 ④ 한 줄 소감 ⑤ 마지막에 "어느 쪽이 편했나" |
| 휴식 | 조건 사이 **5분 이상**, 그리고 "처음 상태로 돌아왔다"고 할 때까지 |
| 인원 | 팀에서 정함(가능한 만큼, 최소 인원 확정 필요). 같은 사람이 두 조건을 다 하므로 적은 인원으로도 비교 가능 |

- 점프대(818m)는 두 조건 모두 같게 둡니다. 결과에 점프대 이야기가 나오면 소감에 적어 둡니다.
- 시작 전에 **연습 1랩**(옵션 켬)으로 조작만 익히게 하고, 연습 뒤 쉬었다가 시작 전 SSQ를 받습니다.

## 2. 진행 순서 (1인 약 25~30분)

1. **안내·동의** (3분) — 아래 3절 안내문을 읽어 주고 동의를 받음. 참가자 번호 부여(이름 기록 안 함)
2. **기본 정보** (1분) — 나이대(10대/20대/30대 이상), VR 경험(없음/몇 번/자주), 차·배 멀미를 잘 하는지(예/아니오)
3. **연습** — 옵션 켬, 서킷 1랩. 헤드셋 착용·리센터(Y)·핸들 잡기 안내 → 헤드셋 벗고 2분 휴식
4. **시작 전 SSQ** (1분)
5. **조건 1** — 진행자가 X 1.5초로 조건 설정(`COMFORT ON/OFF` 확인) → 타임어택 3랩 → 바로 SSQ + 완주 시간 + 한 줄 소감
6. **휴식** 5분 이상
7. **조건 2** — 같은 방식
8. **마지막 질문** — "어느 쪽이 더 편했나요? (A/B/차이 없음)", 하고 싶은 말

**중단 규칙**: 참가자가 원하거나 메스꺼움이 심해 보이면 **즉시 중단**하고 헤드셋을 벗김. 그 조건은 "중도 포기"로 기록하고, 그때의 SSQ를 받음(가능하면). 앉아서 충분히 쉬게 하고 괜찮아질 때까지 기다림.

## 3. 참가 안내문 (읽어 주기)

> 이 테스트는 VR 카트 레이싱 게임 수업 과제에서 **멀미를 줄이는 옵션이 효과가 있는지** 알아보기 위한 것입니다.
>
> - 헤드셋을 쓰고 약 3분씩 **두 번** 주행합니다. 한 번은 멀미 줄이는 옵션을 켜고, 한 번은 끕니다. 전후로 몸 상태를 묻는 짧은 설문(16문항)에 답합니다. 전체 약 30분.
> - VR 주행 중 **어지러움·메스꺼움 같은 멀미가 생길 수 있습니다.** 불편하면 **언제든 말씀하시면 바로 멈추고**, 그만둬도 아무 불이익이 없습니다.
> - 이름은 적지 않고 **번호로만 기록**합니다. 모은 정보(나이대, VR 경험, 설문 점수, 주행 시간, 소감)는 **수업 발표에서 평균·그래프로만** 쓰고, 끝나면 지웁니다.
> - 참여하시겠습니까?

## 4. SSQ 설문지 (Kennedy et al., 1993 — 한국어는 팀 번역)

**지금 이 순간** 각 증상이 어느 정도인지 골라 주세요. **0 = 없음, 1 = 약간, 2 = 보통, 3 = 심함**

| 번호 | 증상 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- | --- |
| 1 | 전반적인 불편감 | ☐ | ☐ | ☐ | ☐ |
| 2 | 피로감 | ☐ | ☐ | ☐ | ☐ |
| 3 | 두통 | ☐ | ☐ | ☐ | ☐ |
| 4 | 눈의 피로 | ☐ | ☐ | ☐ | ☐ |
| 5 | 초점 맞추기 어려움 | ☐ | ☐ | ☐ | ☐ |
| 6 | 침이 평소보다 많이 나옴 | ☐ | ☐ | ☐ | ☐ |
| 7 | 땀이 남 | ☐ | ☐ | ☐ | ☐ |
| 8 | 메스꺼움 | ☐ | ☐ | ☐ | ☐ |
| 9 | 집중하기 어려움 | ☐ | ☐ | ☐ | ☐ |
| 10 | 머리가 꽉 찬 느낌(묵직함) | ☐ | ☐ | ☐ | ☐ |
| 11 | 시야가 흐림 | ☐ | ☐ | ☐ | ☐ |
| 12 | 어지러움 (눈을 뜨고 있을 때) | ☐ | ☐ | ☐ | ☐ |
| 13 | 어지러움 (눈을 감았을 때) | ☐ | ☐ | ☐ | ☐ |
| 14 | 빙빙 도는 느낌(현기증) | ☐ | ☐ | ☐ | ☐ |
| 15 | 속이 불편함(배 속이 신경 쓰임) | ☐ | ☐ | ☐ | ☐ |
| 16 | 트림 | ☐ | ☐ | ☐ | ☐ |

출처: Kennedy, R. S., Lane, N. E., Berbaum, K. S., & Lilienthal, M. G. (1993). Simulator Sickness Questionnaire: An enhanced method for quantifying simulator sickness. *The International Journal of Aviation Psychology*, 3(3), 203–220.

### 점수 계산

| 하위 척도 | 포함 문항 | 가중치 |
| --- | --- | --- |
| 메스꺼움 N (Nausea) | 1, 6, 7, 8, 9, 15, 16 | 합 × 9.54 |
| 눈 피로 O (Oculomotor) | 1, 2, 3, 4, 5, 9, 11 | 합 × 7.58 |
| 방향 감각 D (Disorientation) | 5, 8, 10, 11, 12, 13, 14 | 합 × 13.92 |
| **전체 TS** | N·O·D 원점수 합 | (N합 + O합 + D합) × 3.74 |

한 문항이 두 척도에 들어가기도 합니다(원 논문 그대로). **비교는 조건별 "주행 후 TS − 시작 전 TS"** 로 봅니다.

## 5. 기록 양식 · 계산

- 기록: [`ssq/ssq_record_template.csv`](ssq/ssq_record_template.csv)를 복사해서 **레포 밖**에 저장합니다(개인 정보가 없더라도 원자료는 커밋하지 않음). 참가자 1명 = 3줄(`pre`, `A`, `B`).
- 계산: `python docs/ssq/ssq_score.py 기록.csv` → 줄마다 N·O·D·TS, 조건별 평균, 시작 전 대비 증가량, A와 B 차이(scipy가 있으면 Wilcoxon 부호 순위 검정).
- 발표에는 조건별 평균 TS(막대 + 참가자별 선), "더 편했던 쪽" 응답 수, 중도 포기 수를 씁니다.
