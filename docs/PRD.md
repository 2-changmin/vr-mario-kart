# PRD — VR Mario Kart

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트 | VR Mario Kart (가칭) |
| 형태 | 가상현실 수업 과제, 2인 팀 |
| 한 줄 소개 | VR 헤드셋을 쓰고 두 손으로 핸들을 잡고 달리는, 3분짜리 캐주얼 카트 레이싱 |
| 플랫폼 | Meta Quest 2/3 (Standalone), 개발 중에는 PC + XR Device Simulator |

## 2. 배경 & 목표

마리오카트의 "누구나 바로 즐기는" 재미를 VR로 옮긴다. 화면을 보는 대신 **카트에 직접 앉아** 핸들을 돌리는 몰입감이 핵심이다.

### 목표
1. **VR 몰입감** — 실제로 핸들을 잡고 돌리는 조작
2. **쉬운 플레이** — 설명 없이 30초 안에 조작을 이해
3. **완주 가능한 한 판** — 메뉴 → 레이스(3랩) → 결과 → 재시작 흐름이 끊김 없이 동작
4. **편안함** — 멀미를 줄여 시연 중 누구나 끝까지 플레이

### 비목표 (이번 과제 범위 밖)
- 온라인/로컬 멀티플레이
- 여러 캐릭터·카트 커스터마이징
- 다수의 트랙 (트랙은 1개 + 테스트 트랙)
- 저장/진행도 시스템, 상점

## 3. 타깃 사용자

- 수업 시연 참관자 (VR 경험이 적을 수 있음)
- 짧게 즐기는 캐주얼 게이머

→ 조작은 단순하게, 튜토리얼 없이도 알 수 있게, 한 판은 3분 내외.

## 4. 핵심 경험 (Core Loop)

```
메인 메뉴 ─▶ 카운트다운(3,2,1,GO) ─▶ 주행 (조향·가속·드리프트·아이템) ─▶ 3랩 완주 ─▶ 결과(순위/기록) ─▶ 재시작 or 메뉴
```

## 5. 주요 기능

| 우선순위 | 기능 | 설명 |
| --- | --- | --- |
| P0 | VR 카트 탑승 & 핸들 조향 | 카메라가 카트 좌석에 고정, 두 손으로 핸들을 잡고 돌려 조향 |
| P0 | 카트 주행 | 트리거로 가속, 그립/버튼으로 브레이크·후진 |
| P0 | 트랙 & 랩 | 체크포인트 기반 랩 카운트, 3랩 완주 시 종료 |
| P0 | 레이스 흐름 | 카운트다운 → 레이스 → 결과 화면 |
| P1 | 드리프트 & 부스트 | 드리프트 유지 시 부스트 게이지, 대시 패드 |
| P1 | 아이템 | 아이템 박스 → 부스터 / 바나나 / 쉘 중 랜덤 |
| P1 | AI 상대 | 웨이포인트를 따라 달리는 AI 카트 3대, 실시간 순위 |
| P1 | UI | 월드 스페이스 메뉴, 인게임 HUD(랩/순위/속도/아이템) |
| P1 | 멀미 저감 | 속도 비례 비네팅, 수평 유지 옵션 |
| P2 | 사운드 & 이펙트 | 엔진음, 부스트, 충돌, BGM, 파티클 |
| P2 | 메인 트랙 꾸미기 | 환경 에셋, 장애물, 점프대 |

## 6. 조작 (Quest 컨트롤러 기준)

| 입력 | 동작 |
| --- | --- |
| 양손 Grip (핸들 위) | 핸들 잡기 → 손 위치로 핸들 회전 = 조향 |
| 오른손 Trigger | 가속 |
| 왼손 Trigger | 브레이크 / 후진 |
| A 버튼 | 드리프트 (누르고 있는 동안) |
| B 버튼 | 아이템 사용 |
| 메뉴 버튼 | 일시정지 |
| (대체 조작) 왼손 스틱 | 핸들을 잡지 않았을 때 조향 |

## 7. 성공 기준

- Quest에서 **72fps 이상** 유지
- 처음 해보는 사람이 설명 없이 **1랩 완주**
- 메뉴 → 레이스 → 결과 → 재시작 흐름에서 **크래시·진행 불가 버그 0건**
- 시연자 대부분이 멀미 없이 3랩 완주
