# 통합 테스트 체크리스트 (#16)

메뉴 → 레이스 → 결과 → 재시작 → 메뉴 전체 흐름과 기능을 확인하는 표입니다. **PC 자동** 열은 에디터 자동 테스트 결과, **Quest** 열은 실기기 테스트 날에 채웁니다. 문제가 나오면 `type: bug` 이슈로 올리고 담당자를 지정합니다.

- **PC 자동 테스트 다시 돌리기**: Unity 메뉴 **VRKart > 통합 자동 테스트 (메뉴→레이스→결과→타임어택)** (`Scripts/Race/Editor/RaceFlowSmokeTest.cs`). 약 2분, 결과는 `Logs/RaceFlowTest.txt`와 콘솔. 플레이어 카트도 AI가 몰고 4배속으로 돌며, 버튼은 화면 대신 `Button.onClick`을 직접 부릅니다. 내 서킷 타임어택 기록은 백업했다가 되돌립니다.
- 표시: ✅ 통과 · ❌ 실패 · — 해당 없음(그 환경에서 확인 불가) · 빈칸 = 아직 안 함

마지막 PC 자동 확인: **2026-10-11**, `main` + #63 — 통과 24 / 실패 0, 오류 로그 0
